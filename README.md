# Ahmed ElMetwally Electrical Engineering Portfolio

This repository publishes Ahmed ElMetwally's electrical engineering portfolio at:

https://ahmedoelmetwally.github.io/

The portfolio includes professional experience, education, engineering projects, certifications, images, reports, code samples and downloadable model files.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

GitHub Actions deploys the generated static site automatically after changes are pushed to the `main` branch.
